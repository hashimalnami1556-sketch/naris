# NARIS Unity Product Context

- Product: NARIS / Ash Gate playable prototype
- Engine: Unity 6000.3.14f1
- Master production engine remains Unreal Engine 5.7; Unity is a portable prototype/reference implementation.
- Core loop: explore Ash Gate, defeat guardians, collect 3 embers, return to the gate.
- Platforms: Windows/macOS/Linux desktop first, then WebGL/mobile profiles.
- Input: keyboard/mouse + gamepad baseline; touch profile reserved for mobile overlay.
- Accessibility/UI: scalable HUD, pause/resume, save/load, clear combat state, RTL-ready typography later.
- Visual identity: Ember Orange, Aether Violet, Mist Cyan, Ancient Gold over ash/basalt dark fantasy.
- Current blocker: Unity licensing on AsusRog returns code 198 before compilation/test execution.
