# قبول التحكم — فحوص داخل Unreal لم تُنفّذ بعد

الحالة الحالية لكل صف أدناه: غير مختبر داخل المحرك. نجاح الاختبارات المحلية يخص القواعد المشتركة والواجهات المحاكاة فقط.

| الفحص | الإجراء | دليل القبول المطلوب |
|---|---|---|
| إدخال قديم | أوقف تحديث Axis2D مع بقاء آخر قيمة غير صفرية، ثم أعد إرسالها | تختفي مساهمة الإدخال خلال InputTimeoutSeconds؛ تعود فقط مع عينة جديدة؛ الفرملة الفيزيائية تُقاس منفصلة |
| انتقال المتحكم | بدّل Controller بين حدث الإدخال وTick، وكرر عند pause/UI | لا تُعاد قيمة المتحكم السابق؛ صفر مرشح الإدخال؛ اختبر تحريرًا بزمن إطار صفري |
| UHT/UBT | تجميع Editor حقيقي على UE 5.7 بعد استبدال الإضافة كاملة | سجل بناء ناجح يذكر إصدار المحرك وعدم وجود تحذيرات reflection غير معالجة |
| إدخال حر | لوحة مفاتيح ويد؛ 30/60/120fps؛ ضغط وتحرير واتجاه قطري | الاستجابة المسجلة من وصول حدث الإدخال إلى الحركة؛ وسجل منفصل لزمن الجهاز إلى العرض إن قيس |
| الميزانية الزمنية | قياس عند 30/60/120، مع تاريخ/جهاز/طريقة القياس | هدف أقل من 100ms للاستجابة المحسوسة؛ لا تستبدله بقيمة ResponseSeconds |
| بدء/توقف | مشي بطيء ثم كامل ثم تحرير وتكرار عشر مرات | مسافة التوقف وثبات الانتقال، دون ذيل إدخال أو انزلاق مرئي واضح |
| اتجاه | عكس 180° ومراجعة إطار بإطار؛ قفل/فك قفل وهدف يمر خلف الشخصية | لا قفز اتجاه؛ تسارع دوران مضبوط؛ لا مصدر دوران منافس |
| الحركات | Blend Space وسلاسل Start/Stop/Pivot/Turn مع Slot القتال | حركات فعلية مطابقة للهيكل، مزج 0.1–0.2 ثانية، دون قطع مرئي |
| القدم | أرض مستوية ومنحدر ودرج مع Foot Placement/IK | تسجيل جانبي/خلفي يثبت ملامسة القدم وتناسق السرعة وطول الخطوة |
| الكاميرا | حر/قتال/قفل/فك قفل؛ حركة حادة وعائق قريب | التأخر أقل في القتال، وعدم قص الجدران أو تكرار كاميرات |
| رفض التشغيل | Montage مفقود أو Skeleton خاطئ أو فشل Montage_Play | لا كلفة ولا دفاع جديد ولا بداية قتال كاذبة |
| الإصابة | ضرر أثناء الضربة وأثناء قبول Montage_Play | إلغاء الضرب والدفاع؛ Hit ثم Recovery/Free؛ لا كلفة للفعل المرفوض |
| الإلغاء | زر خارج النافذة ثم داخل نافذة بعد الزمن صفر | رفض خارجها؛ قبول داخلها؛ حفظ الكلفة والتعافي؛ عدم تنفيذ أمر مخزون قديم |
| التعافي | حاول هجومًا أو مراوغة خلال التعافي وبعده | لا تجاوز للمهلة؛ تخزين صالح واحد قرب النهاية |
| انتهاء Buffer | عند المهلة بالضبط، وبعدها، وبعد hitch | قبول الحد الشامل؛ رفض الأمر القديم بعد تجاوز المهلة |
| واجهة/تركيز | فتح القائمة وفقدان التركيز وUnpossess أثناء إمساك العصا | لا حركة أو أمر قتالي عالق عند العودة |
| شبكة | Listen + Dedicated Server مع latency/loss معلومين | سلطة السيرفر على الكلفة والإلغاء والهدف؛ طَور موحّد دون افتراض تنبؤ محلي |
| تغليف | تشغيل حزمة Development خارج Editor | الحركة والقتال والكاميرا تعمل في النسخة المغلفة؛ وجود EXE وحده لا يكفي |

معيار «لا فرق بين الآلي وUnreal» يُستبدل بربط كل حالة من القواعد المشتركة بتجربة PIE مقابلة، ثم تسجيل النتيجة والفروق. تكامل CharacterMovement وMontage/Slot والكاميرا والتصادم لا تُثبته اختبارات C++ المعزولة أو محاكاة API.

## الإشارات ليست محتوى حركة

NarisP15LocomotionAnimInstance يوفّر بيانات فقط. لا تعتبر ظهور Starting/Pivoting/Turn intent إثباتًا لتشغيل مقطع أو تثبيت قدم. ليست هناك حركات جديدة داخل هذه المراجعة.
