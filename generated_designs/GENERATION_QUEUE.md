# Generated Designs Queue

All generated and approved visual outputs belong under this directory.

## Naming
`NARIS_<DOMAIN>_<ASSET_ID>_<VARIANT>_<REV>.png`

## Required metadata
Each approved image must have a sibling JSON record containing:
- asset_id
- domain
- prompt
- model/provider
- generation timestamp
- variant
- approval_status
- source_reference
