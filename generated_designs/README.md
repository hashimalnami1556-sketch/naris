# Generated Design References

This directory contains generated concept and presentation references for CALL OF NARIS.

## Rules
- Generated visuals are reference material, not approved runtime assets.
- Every production asset derived from these references must receive a NARIS Asset ID.
- Final assets must pass technical-art, engine integration, performance, gameplay and QA gates.
- Use visuals throughout UI, environment and character production as composition/material/lighting targets, not as direct substitutes for production-ready Unreal assets.
