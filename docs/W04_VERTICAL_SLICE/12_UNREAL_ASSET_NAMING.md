# W04 Unreal Asset Naming Convention

## Prefixes
- `BP_` Blueprint Actor
- `BPC_` Blueprint Component
- `DA_` Data Asset
- `ABP_` Animation Blueprint
- `AM_` Animation Montage
- `AN_` Animation Notify
- `NS_` Niagara System
- `NC_` Niagara Component/Context asset where applicable
- `AC_` Audio Cue
- `WBP_` Widget Blueprint
- `DT_` Data Table
