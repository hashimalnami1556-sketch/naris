# W04 Data Asset Contract

## Boss Data
`DA_BoneBeast` should contain:
- identity / world / arena reference
- phase definitions
- tuning values for HP and damage
- attack set references
- stagger configuration
- rewards / quest completion reference

## Attack Data
Each attack entry should define:
- attack identifier
- animation montage
- damage profile
- stamina impact
- telegraph duration
- hit window
- recovery
- VFX event
- audio event

## Tuning Rule
Numeric values remain `TUNE` until playtest. They must not be hard-coded as lore facts.
