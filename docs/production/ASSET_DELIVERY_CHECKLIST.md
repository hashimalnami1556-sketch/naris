# NARES MASTER — Asset Delivery Checklist

## Gate A — Identity
- [ ] Asset ID unique and canonical
- [ ] Asset Type assigned
- [ ] Department assigned
- [ ] Owner assigned
- [ ] Priority assigned
- [ ] Version assigned
- [ ] Source recorded
- [ ] Runtime format recorded
- [ ] Dependencies recorded

## Gate B — Art
- [ ] Concept approved
- [ ] Model/high-poly approved
- [ ] Low-poly approved
- [ ] UV approved
- [ ] Textures complete
- [ ] Materials complete
- [ ] Rig approved (if applicable)
- [ ] Animation approved (if applicable)

## Gate C — Technical Art
- [ ] Naming convention passes
- [ ] Pivot / scale / rotation pass
- [ ] LOD strategy pass
- [ ] Collision pass
- [ ] Material instance pass
- [ ] Runtime import pass
- [ ] Performance budget recorded

## Gate D — Integration
- [ ] Gameplay integration complete
- [ ] VFX/audio dependencies resolved
- [ ] Blueprint/system references resolved
- [ ] No missing references
- [ ] No duplicate runtime assets

## Gate E — QA / Approval
- [ ] Visual QA PASS
- [ ] Technical QA PASS
- [ ] Engine QA PASS
- [ ] Final QA PASS
- [ ] Documentation complete
- [ ] Lead approval
- [ ] Art Director approval
- [ ] Technical Art approval
- [ ] Game Integration approval
- [ ] FINAL status granted

**Rule:** A missing checkbox blocks FINAL.
