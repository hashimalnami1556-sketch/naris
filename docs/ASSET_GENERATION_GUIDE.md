# NARIS Asset Generation Guide

## Purpose
This guide defines the controlled prompt standard for generating original CALL OF NARIS visual assets. Asset names and prompts are English-only.

## Visual Standard
- Premium AAA dark fantasy + high fantasy.
- Strong color separation and visual saturation; never gray-only.
- Naris Fire: ember orange/red energy.
- Aether Violet: supernatural arcane energy.
- Mist Cyan: atmospheric rim light and spectral effects.
- Ancient Gold: relics, trims, sacred technology.
- Deep charcoal/obsidian shadows provide contrast rather than replacing color.
- Cinematic volumetric lighting, rich PBR material cues, layered atmospheric depth.
- Distinctive silhouettes and readable gameplay shapes.
- No accidental text, logos, watermarks, or copyrighted character imitation.

## Prompt Template
[ASSET TYPE], [SUBJECT], [SILHOUETTE], [MATERIALS], [POWER/VFX], [COLOR SCRIPT], [LIGHTING], [ENVIRONMENT], [CAMERA/COMPOSITION], premium AAA game concept art, production reference, high detail, clean readable design.

## Quality Gate
Reject any result that is: muddy, monochrome, visually generic, anatomically broken, inconsistent with the NARIS silhouette language, missing the requested power cue, unreadable at gameplay scale, or contaminated with unwanted text/watermarks.

## Output Contract
Save approved generated images under `generated_designs/` using immutable Asset IDs and a matching JSON manifest. Keep source prompts and approval state with each asset.
