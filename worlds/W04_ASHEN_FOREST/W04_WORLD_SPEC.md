# W04 — Ashen Forest

## Source basis
W04 is defined in the project material as **غابة الرماد / Ashen Forest**: a forest without leaves, covered by glowing and mysterious aether threads. Its core challenge is a fog maze and aetheric poisoning.

## Vertical Slice scope
- Overgrown Ruins
- Twisted Canopy
- Memory Shrine (Interactive)
- Bone Gate
- Bone Beast Arena
- Elder Sage Thorne
- Lost Warden Spirit
- The Corrupted Heart quest
- Thorn's Memory side quest
- Forest exploration music / ambience
- Bone Beast battle music

## Encounter
The Bone Beast encounter is the first W04 boss integration target. Numeric balance values remain TUNE until playtest.

## Integration contract
Environment → traversal → encounter → boss → phase events → VFX/audio/UI → quest completion → QA.

## Production rule
Every W04 asset must carry a traceable NARIS Asset ID through concept, registry, Unreal integration, QA and approval.
