# NARIS — ASHEN WASTES BLENDER PRODUCTION
Target: Unreal Engine 5
DCC: Blender 4.x
Scale: 1 Blender Unit = 1 meter
Primary modular grid: 2 meters

This is the complete production scaffold for Ashen Wastes.
Concept sheets belong in 02_REFERENCES/ASHEN_WASTES.
Build production geometry in 03_MODELS, materials in 04_MATERIALS,
textures in 05_TEXTURES, effects in 07_VFX, prefabs in 08_PREFABS,
and exports in 12_EXPORT.

Run 14_TOOLS/BLENDER/naris_ashen_wastes_setup.py in Blender to initialize
metric units, snap workflow, collections and scale references.
